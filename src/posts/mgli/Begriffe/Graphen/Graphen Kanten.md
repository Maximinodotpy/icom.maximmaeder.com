> [!abstract] Definition
> Ist $G=(V,E)$ ein ungerichteter [[Graph]], so nennt man ein Element $[x,y] \in E$ (mit $x,y \in V$) die Kante von $G; x,y$ heissen Endknoten.
>
> Eine Kante gibt an, ob zwei [[Graphen Knoten|Knoten]] miteinander in Beziehung stehen, bzw. ob sie in der bildlichen Darstellung des [[Graph|Graphen]] verbunden sind. In einem gerichteten [[Graph|Graphen]] ist eine Kante ein geordnetes Paar von [[Graphen Knoten|Knoten]], in einem ungerichteten [[Graph|Graphen]] ist eine Kante eine [[4-mengen|Menge]] zweier [[Graphen Knoten|Knoten]]. Zwei [[Graphen Knoten|Knoten]], die durch eine Kante verbunden sind, heißen benachbart oder adjazent.
