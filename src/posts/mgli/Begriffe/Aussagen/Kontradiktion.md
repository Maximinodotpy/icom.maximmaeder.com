Wenn eine [[Logische Formel#Logische Formel|logische Formel]] für alle Belegungen stets den Wahrheitswert 0 hat, dann nennt man diese Formel Kontradiktion: zb. $A ∧ ¬A$ (<span style='color: var(--custom-word-gesproche-blue, blue)'>gesprochen: A und nicht A</span>).

| $A$ | $\neg A$ | $A \land \neg B$ |
| --- | -------- | ---------------- |
| 0   | 1        | 0                |
| 0   | 1        | 0                |
| 1   | 0        | 0                |
| 1   | 0        | 0                |
