## Lernziele

- [ ] ==🟢Sie verstehen die Fragestellung des Königsberger Brückenproblems.
- [ ] ==🟢Sie können den Unterschied einer Menge und einer Multimenge erklären.
- [ ] ==🟢Sie kennen die Definition von – einfachen [[Graph|Graphen]], – Multigraphen und – gerichteten [[Graph|Graphen]].
- [ ] Sie können geeignete Probleme mit Hilfe von [[Graph|Graphen]] modellieren.
- [ ] Sie können anhand der Graphentheorie das Königsberger Brückenproblem untersuchen.
- [ ] Sie kennen die Definition des Eulerwegs, die besagt, dass jede Kante in einem [[Graphen Wege|Weg]] genau einmal besucht wird.
- [ ] Sie wissen, dass der Grad eines Knotens die Anzahl Kanten ist, die diesen Knoten enthalten.
- [ ] Sie verstehen, wieso es in einem [[Graph|Graphen]] nur eine gerade Anzahl von Knoten mit ungeradem Grad geben kann.
- [ ] Sie wissen, wie zusammenhängende [[Graph|Graphen]] definiert sind.
- [ ] Sie kennen die Eulerbedingung für [[Graphen Eulerweg|Eulerwege]] und können bestimmen, ob es in einem gegebenen [[Graph|Graphen]] einen [[Graphen Eulerweg]] gibt.
- [ ] Sie kennen den Algorithmus von Hierholzer und können damit [[Graphen Eulerweg|Eulerwege]] bestimmen.
- [ ] Sie wissen, dass ein geschlossener [[Graphen Wege|Weg]] bzw. [[Graphen Eulerweg]] ein Kreis bzw. [[Graphen Eulerkreis]] ist und kennen die Definition des Eulergraphen.
- [ ] Sie kennen die Eulerbedingung für Eulerkreise und können den Algorithmus von Hierholzer erweitern, um Eulerkreise zu bestimmen.
- [ ] Sie kennen die Darstellung eines [[Graph|Graphen]] formal als 2-Tupel und die graphische Darstellung.
- [ ] Sie wissen, dass durch eine Kante verbundene Knoten adjazent heissen und dass mit einem bestimmten Knoten verbundene Kanten inzident zu diesem Knoten sind.
- [ ] Sie wissen, dass [[Graph|Graphen]] [[Graphen Spannbäume|gewichtet]] sein können.
- [ ] Sie können [[Graph|Graphen]] in Matrixschreibweise, nämlich als Adjazenzmatrix, darstellen und kennen einige wichtige Eigenschaften von Adjazenzmatrizen.
- [ ] Sie können bestimmen ob zwei kleine [[Graph|Graphen]] isomorph sind.
- [ ] Sie kennen die Definition eines Baums und seinen Blättern.
- [ ] Sie verstehen, dass je zwei Knoten in einem Baum durch genau einen [[Graphen Wege|Weg]] verbunden sind
- [ ] Die Definition des Zusammenhangs ergänzen Sie durch die Zusammenhangskomponente.
- [ ] Sie wissen, was ein [[Graphen Spannbäume|Spannbaum]] (aufspannender Baum) ist.
- [ ] Sie verstehen, was passsiert, wenn man in einem Baum eine Kante entfernt oder dazufügt.
- [ ] Sie können erklären, wieso die Anzahl der Kanten in einem Baum mit n Knoten immer n − 1 ist.
- [ ] Sie können mit der Cayley-Formel die Anzahl der aufspannenden Bäume für einen vollständigen [[Graph|Graphen]] mit n Knoten bestimmen.
- [ ] Sie können zu einem Baum einen Prüfercode bestimmen und Sie können auch anhand des Prüfer- codes den dazugehörigen Baum aufzeichnen.
- [ ] Sie können Teilgraphen eines [[Graph|Graphen]] bestimmen und testen, ob dieser einen [[Graphen Spannbäume|Spannbaum]] definiert.
- [ ] Sie können die Kosten eines Spannbaums bestimmen, was vor allem bei gewichteten [[Graph|Graphen]] verwendet wird.
- [ ] Mittels der Algorithmen von Kruskal und Prim können Sie einen minimalen [[Graphen Spannbäume|Spannbaum]] bestimmen.
