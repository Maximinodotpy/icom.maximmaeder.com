## Lernziele

- [ ] Sie können die Laufzeit dieses Algorithmus für kleine Zahlenbeispiele berechnen und informell begründen, wie die Laufzeit für ein allgemeines n bestimmt werden kann.
- [ ] Sie können das Summenzeichen Σ einsetzen, um Summen, in denen die Summanden eine gewisse Regelmässigkeit aufweisen, kompakt darzustellen.
- [ ] Sie kennen die wichtigsten Rechenregeln für das Summenzeichen und können damit Summen vereinfachen.
- [ ] Sie können das Produktzeichen Π einsetzen, um Produkte, in denen die Faktoren eine gewisse Regelmässigkeit aufweisen, kompakt darzustellen.
- [ ] Sie kennen die wichtigsten Rechenregeln für das Produktzeichen und können damit Produkte vereinfachen.
- [ ] Sie können einfache (verschachtelte) Summen und Produkte berechnen.
- [ ] Sie verstehen, wieso mit der vollständigen Induktion durch die Induktionsverankerung und den Induktionsschritt eine All-Aussage allgemein bewiesen wird.
- [ ] Sie können die vollständige Induktion anwenden, um All-Aussagen zu beweisen.
- [ ] Sie können erklären, wie der Algorithmus für die Türme von Hanoi funktioniert
