## Lernziele

- [ ] Sie wissen, was eine Rekursionsgleichung k-ter Ordnung ist.
- [ ] Sie wissen, dass eine Rekursionsgleichung k-ter Ordnung mehr als eine Folge als Lösung haben kann.
- [ ] Sie wissen, dass eine Rekursionsgleichung k-ter Ordnung zusammen mit k Anfangsbedingungen eine eindeutige Folge definiert.
- [ ] Sie können lineare Rekursionsgleichungen mit konstanten Koeffizienten erkennen und davon die Ordnung sowie den Störterm bestimmen.
- [ ] Sie können die allgemeine Lösung einer homogenen linearen Rekursionsgleichung erster Ordnung bestimmen.
- [ ] Sie wissen, welchen Ansatz Sie machen müssen, um eine spezielle Lösung einer Rekursionsgleichung erster Ordnung mit konstanten Koeffizienten mit einem Störterm vom Typ „Polynom mal Exponentialfunktion“ zu berechnen.
- [ ] Sie können lineare Rekursionsgleichung erster Ordnung mit konstanten Koeffizienten mit einem Störterm vom Typ „Polynom mal Exponentialfunktion“ und gegebener Anfangsbedingung lösen.
- [ ] Sie können Rekursionsgleichungen, die typischerweise bei der Laufzeitanalyse rekursiver Algorithmen vorkommen, durch Variablensubstitution auf lineare Rekursionsgleichungen erster Ordnung transformieren.
- [ ] Sie können aus der Lösung der transformierten Gleichung durch Rücksubstitution eine Lösung der Ausgangsgleichung herleiten.
