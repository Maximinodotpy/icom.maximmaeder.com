## Lernziele

- [ ] Sie verstehen die reelle Zahlenfolge als eine spezielle Funktion, die jeder natürlichen Zahl n eine andere natürliche Zahl f (n) (das n-te Folgenglied) zuordnet.
- [ ] Sie wissen, was die explizite Darstellung und die rekursive Darstellung einer Folge ist.
- [ ] Sie verstehen die rekursive Darstellung k -ter Ordnung als Erweiterung der einfachen rekursiven Darstellung.
- [ ] Sie können die rekursive Berechnung des n-ten Folgenglieds mit Hilfe eines Rekursionsbaums visualisieren.
- [ ] Sie kennen die Fibonacci-Folge.
- [ ] Sie wissen, wie das Zinseszinsverfahren funktioniert.
- [ ] Sie können die Methode des induktiven Schliessens anwenden, um von einer rekursiv definierten Zahlenfolge eine explizite Darstellung für diese Folge zu finden.
- [ ] Sie können die Vermutung, die Sie durch das induktive Schliessen gefunden haben, beweisen.
