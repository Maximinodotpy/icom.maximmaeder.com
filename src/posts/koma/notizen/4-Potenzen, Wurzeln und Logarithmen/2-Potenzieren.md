## Potenzregeln für die Umformung

| Name                                              | Beispiel                                                                                                                                          | Anmerkung                                                                                                                                                                               |
| ------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [[Produkt]] von Potenz mit gleicher [[Basis]]     | $a^{r + s} = a^r * a^s$                                                                                                                           | Sofern $a > 0$                                                                                                                                                                          |
| [[Division]] von Potenz mit gleicher [[Basis]]    | $a^{r-s} = \frac{a^r}{a^s}$                                                                                                                       | Sofern $a > 0$ (Damit die Basis nicht $0$ ist)                                                                                                                                          |
| Negativer [[Exponent]]                            | $a^{-r} = \frac{1}{a^r}$<br><br>$\frac{5}{4^1} = 5 \cdot 4^{-1}$<br><br>$\frac{5}{4^{-1}} = 5 \cdot 4^{1}$                                        | Sofern $a \neq 0$ ist, entspricht eine Potenz mit negativem Exponenten dem Kehrwert der Potenz mit positivem Exponenten ($1$ über der Potenz). Sie kann z. B. durch Division entstehen. |
| Negativer [[Exponent]] bei einem Bruch            | $\frac{1}{2}^{-1} = \frac{2}{1}$                                                                                                                  | Bei einem Bruch kehrt ein Negativer [[Exponent]] den Bruch um.                                                                                                                          |
| Potenz auf Bruch verteilen                        | $$\left(\frac{2b}{ab - 4}\right)^4 \cdot \left(\frac{ab - 4}{b}\right)^3$$<br>$$= \frac{2^4 \cdot b^4}{(ab - 4)^4} \cdot \frac{(ab - 4)^3}{b^3}$$ | Der Exponent wird auf Zähler und Nenner angewendet. Steht dort ein Produkt, wird jeder Faktor einzeln potenziert.                                                                       |
| Exponent $0$                                      | $a^0 = 1$                                                                                                                                         | Sofern $a$ nicht $0$ ist dann ergibt die $0$-te Potenz von jeder Basis $1$.                                                                                                             |
| [[Produkt]] von Potenzen mit gleichen Exponenten  | $(a * b)^r = a^r * b^r$                                                                                                                           | Sofern $a * b \neq 0$.                                                                                                                                                                  |
| [[Division]] von Potenzen mit gleichem Exponenten | $(\frac{a}{b})^r = \frac{a^r}{b^r}$                                                                                                               | Sofern $a \neq 0 \wedge b \neq 0$.                                                                                                                                                      |
| Potenz einer Potenz                               | $a^{r^{s}} = a^{r*s}$<br><br>$(a + b^3)^2 = a^2 + b^6$                                                                                            | Sofern $a \neq 0$.                                                                                                                                                                      |
|                                                   | $a^{\frac{m}{n}} = \sqrt[n]{a^m} = (\sqrt[n]{a})^m$                                                                                               |                                                                                                                                                                                         |
Potenzieren ist weder [[koma/spick midterms/formelblatt#^Assoziativgesetz|Kommutativ]] noch [[koma/spick midterms/formelblatt#^Assoziativgesetz|Assoziativ]].
