## Potenzregeln für die Umformung

| Name                                              | Beispiel                                            | Anmerkung                                                                                                                                    |
| ------------------------------------------------- | --------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------- |
| [[Produkt]] von Potenz mit gleicher [[Basis]]     | $a^{r + s} = a^r * a^s$                             | Sofern $a > 0$                                                                                                                               |
| [[Division]] von Potenz mit gleicher [[Basis]]    | $a^{r-s} = \frac{a^r}{a^s}$                         | Sofern $a > 0$ (Damit die Basis nicht $0$ ist)                                                                                               |
| Negativer [[Exponent]]                            | $a^{-r} = \frac{1}{a^r}$                            | Sofern $a$ nicht $0$ ist dann ist die minus $R$-te Potenz das gleich wie $1$ über der Potenz.<br>Kann zb. auch durch die Division entstehen. |
| Exponent $0$                                      | $a^0 = 1$                                           | Sofern $a$ nicht $0$ ist dann ergibt die $0$-te Potenz von jeder Basis $1$.                                                                  |
| [[Produkt]] von Potenzen mit gleichen Exponenten  | $(a * b)^r = a^r * b^r$                             | Sofern $a * b \neq 0$.                                                                                                                       |
| [[Division]] von Potenzen mit gleichem Exponenten | $(\frac{a}{b})^r = \frac{a^r}{b^r}$                 | Sofern $a \neq 0 \wedge b \neq 0$.                                                                                                           |
| Potenz einer Potenz                               | $a^{r^{s}} = a^{r*s}$                               | Sofern $a \neq 0$.                                                                                                                           |
|                                                   | $a^{\frac{m}{n}} = \sqrt[n]{a^m} = (\sqrt[n]{a})^m$ |                                                                                                                                              |
Potenzieren ist weder [[koma/formelblatt#^Assoziativgesetz|Kommutativ]] noch [[koma/formelblatt#^Assoziativgesetz|Assoziativ]].
